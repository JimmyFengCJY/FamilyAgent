## 交付边界

这是本地开发验证版，完整生产架构的剩余差异列在 README。默认确定性演示与真实模型严格区分；示例内容不能用于判断专业建议质量。心理支持与财务场景不接医疗处方或交易工具。

后续建议优先级：

1. 接入实际模型，构建代表性问题集，比较单 Agent 与多 Agent 的质量和成本。
2. 优化会议澄清、分歧收敛和跨轮上下文；为计划增加版本修改与排期。
3. 按实际使用需求加入文件账本、授权检索、外部日历与更完整的提醒。
4. 多人上线前完善成员管理、数据迁移、生产认证、备份与安全评审。
