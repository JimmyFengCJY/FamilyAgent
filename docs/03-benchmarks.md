## 本项目的验证目标

1. R2：相同合成输入下比较单/多 Agent 的质量、Token 与延迟。没有双侧评分时不宣称质量提升；不同总计算量不宣称公平等成本比较。
2. 后续协作升级：独立首轮分析、结构化分歧、有限澄清，以 R2 基线衡量收益。
3. 保留现有优势：检查点恢复、会议逐成员确认、任务单独授权、事务幂等和私密空间隔离。

参考项目会变化；实施具体能力前重新核对对应源码与许可证，避免把文档中的设想当作已验证实现。
