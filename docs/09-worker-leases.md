# Worker 租约续期与进程故障恢复

R12 为每次执行代次增加有上限的心跳续租，并用实际子进程验证竞争和进程死亡接管。它延续 R8 的结果提交保护和 R11 的实体表，没有新增迁移或修改模型协议。

## 执行生命周期

1. claim 在短写事务内领取候选，生成唯一 attempt_id，保存 worker、lease_until、lease_deadline，并重置当前代次的续租次数/时间。
2. tick 在该代次执行期间启动独立心跳线程，覆盖上下文准备、模型等待、工具检查点与只读工具等待；心跳不携带业务事务连接。
3. 每次续租使用独立连接与短 BEGIN IMMEDIATE。获得锁后采样当前时间，用单条条件 UPDATE 核对运行 running、worker/attempt/deadline 一致、旧租约与续租窗口仍有效。
4. UPDATE 只修改 lease_until、lease_renewed_at、lease_renewals；不把领取时的整个旧运行写回，避免覆盖新检查点、计费或控制状态。成功时在同一事务写 lease.renewed 事件，不记录提示词和工具正文。
5. 条件不满足则停止心跳，不复活过期租约。业务返回后仍需通过原有 owns/权限检查，续租成功不等于最终响应一定可采纳。
6. 正常/异常离开执行范围时通知线程退出；Worker 停止时不再安排后续续租。已经进入数据库操作的一次续租可能先完成；不主动把仍在进行的底层调用提前释放给其他 Worker。

## 默认参数与上限

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| lease_seconds | 120 秒 | 从当前时间起授予的租期 |
| heartbeat_interval | 30 秒 | 相邻续租检查间隔 |
| max_attempt_seconds | 600 秒 | 从本次领取起的最长续租窗口；不是整个运行的总时限 |
| 续租连接锁等待 | 0.1 秒 | 避免心跳长期占用等待线程；忙锁在下个间隔重试 |

Harness 构造参数允许测试注入短租期，校验正数/有限值、心跳小于租期一半、窗口不短于租期。当前没有增加用户环境变量或网页设置。领取和续租后的边界时间向下取毫秒精度，避免 SQLite JSON 浮点序列化在严格期限附近产生微秒漂移。

每次续租最多到 lease_deadline，不会因底层永久阻塞而无限延期。心跳线程还使用单调时钟限制自身生命周期；跨进程领取/过期仍依赖同一主机的墙上时钟，系统时钟大幅调整会影响判定，不是多机分布式时钟方案。

## 失效与恢复

- **正常长调用**：在原始 120 秒之后，只要续租持续成功，其他 Worker 不能领取该运行。
- **进程崩溃/强制结束**：线程随进程消失，最后一次租期到期后，其他 Worker 以新 attempt_id 接手。不会立即接手，也不依赖检测特定 PID。
- **暂停/取消/新代次**：条件 UPDATE 失败，旧心跳退出；旧响应仍按执行代次丢弃。
- **数据库忙/不可用**：锁冲突下一间隔重试；无法及时续租则租约过期，不能事后复活。其他数据库错误停止该心跳并只记录固定脱敏提示。当前没有单独的心跳故障监控面板。
- **达到最大窗口**：停止续租。底层请求可能仍在执行；新 Worker 可在租约到期后接管，旧请求返回内容不采纳，已报告 Token 仍按代次计账。

模型调用结束但结果尚未提交时崩溃，仍可能重新请求模型并再次计费。已经提交的 pending_tool 可沿原 call_id 恢复，不重做已完成的模型请求；只读工具本身可能物理执行多次。续租没有提供外部 exactly-once 或强制中断网络请求的能力。

## 验证证据与范围

tests/test_leases.py 和 tests/worker_process_fixture.py 使用临时库、固定离线 Gateway、文件屏障和独立 Python 子进程，不携带模型密钥。

- 模型阻塞超过初始短租期，观察实际续租，另一个进程领取失败；强制杀死原进程后，等待实际持久租期到期，新进程完成运行，只发布一条 Agent 消息。
- 工具在检查点之后阻塞超过初始租期；强制终止后，新进程恢复同一 call_id，calls/tool_requests 各为 1，测试直接禁止恢复阶段调用模型。
- 达到短续租窗口后，第二进程完成新代次，再释放旧模型；只保留新内容，旧响应被丢弃，两个已报告输入 Token 仍计入原运行。
- 单独验证状态/Worker/代次/期限变化、租约过期拒绝续租、忙锁后无法复活、线程停止；真实 services.api.app.worker 入口在 demo 下完成合成运行并响应 SIGTERM 正常退出。

故障注入使用缩短的 0.6 秒租期和 0.9 秒窗口等参数，并未让真实请求运行 10 分钟。子进程试验验证了具体恢复行为，不等于多 Worker 压力测试、多机部署或生产 SLA。SQLite 仍是单写者，心跳增加写入和事件量；默认 Worker 仍串行执行，暂停/取消不保证立即终止底层调用。共享数据库升级仍应停掉并统一所有 Worker 版本。
